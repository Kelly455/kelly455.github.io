# Travel Agency

A travel agency website built with HTML, CSS, and JavaScript, designed to present
travel information through a live, accessible web page. The project is deployed
using GitHub Pages and can be viewed directly online without downloading or
setting up the project locally.

## Features
- Welcome section introducing the travel agency
- Interactive name input with a Submit button
- Age input with a "Check Age" button to test conditional logic
- Destination buttons for Beach Getaway, Mountain Retreat, and City Tour

## Built With
- HTML5
- CSS3
- JavaScript

## How to Run
1. Visit the live website at kelly455.github.io
2. No download or local setup is required to view the deployed project

## What I Learned

This project was my first experience deploying a website to a live hosting
environment. I learned that code that works correctly locally can still run
into problems when it is deployed. In particular, I had to troubleshoot a
GitHub Pages deployment issue caused by the index.html file needing to use
the exact lowercase filename required for the site to load correctly. This
taught me that building a project is only part of the process — understanding
how the project behaves in a real hosting environment is important too.
